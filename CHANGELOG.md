# Changelog

## 0.1.0-experimental

- Separate Status, Disable Updates and Enable Updates ELF payloads.
- Stored, nonempty placeholders at the two documented PS5 update paths.
- Actual mount check, conservative ownership checks, explicit operations and per-action logs.
- Preserve real/unknown files; handle partial failures without a success notification.
- Pinned SDK, GitHub Actions builds, SHA-256 manifest, source archives and English/Persian guides.
- Host filesystem tests with ASan/UBSan. No console protection or reboot-persistence claim.
